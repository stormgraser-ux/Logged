### 15:30 — CWS won't accept blanket content_scripts on all URLs
Chrome Web Store reviewers will reject extensions with `https://*/*` in manifest `content_scripts`. The fix: move broad matching to `optional_host_permissions` and register content scripts dynamically via `chrome.scripting.registerContentScripts()`. Requires `scripting` permission. The permission request must happen from a user gesture in a foreground context (popup), not from the service worker — `chrome.permissions.request()` is only valid in foreground pages.

### 15:45 — chrome.storage.session is the SW cache fix
In-memory variables in MV3 service workers die when Chrome kills the idle SW (~5 minutes). `chrome.storage.session` persists across SW restarts within a browser session and doesn't require any extra permissions beyond `storage`. Perfect for caching ephemeral data like cross-tab job handoff and subscription state.

### 16:00 — GitHub Pages requires a public repo on free plans
GitHub Pages won't work on private repos without GitHub Pro/Enterprise. If you need to host a privacy policy or docs page, either make the repo public or use an alternative (Gist, Netlify Drop, etc). For Chrome extensions this is fine — the source is visible to anyone who installs the extension anyway.
