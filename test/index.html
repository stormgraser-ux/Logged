Logged — Detector Test Suite

Test all 6 detectors without applying to real jobs

Setup

  1. Build the extension: npm run build
  2. Start the test server from the project root: python3 -m http.server 8765
  3. Open http://localhost:8765/test/ in Chrome
  4. Click a test below to run it
